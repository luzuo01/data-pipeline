# 五条自然语言原文验收（2026-11-01）

本轮按 `scripts/five_case_prompts.json` 中的五条原文依次从网页提交，seed=0、默认分辨率和后台 UE 渲染。没有用手写 SceneSpec 替代自然语言输入。第 5 条的预期结果是明确拒绝不支持的倒水和毛巾擦拭，而不是生成替代任务。

## 修复内容

- 圆柱推动：扩展物理技能的形状范围，使用圆形接触半径和较低推点；禁止在推动轨迹中抓取或抬升物体。未放宽末尾成功保持或碰撞检查。
- UE 几何：圆柱不再被替换为 Cube；按形状选用引擎基本网格，并修正 SAPIEN 圆柱局部 X 轴与 UE 圆柱 Z 轴之间的旋转。实际读取引擎 Cylinder bounds 确认其原生尺寸为 100×100×100 cm。
- 本地语义解析：绑定方块颜色、相对大小和指定移动对象，支持多色物体描述；堆叠中的红色小方块与蓝色大方块角色正确。
- 不支持的任务：液体倾倒、毛巾擦拭明确失败，不进入默认抓取任务。
- 页面：新任务开始及失败/中断后清除旧视频和截图；失败记录刷新后也不展示上一条任务的产物。
- 验证器：大型 Arrow 缓存默认写入数据集所在磁盘，仍尊重显式 HF_DATASETS_CACHE，解决 C 盘空间不足导致 reader 验证失败。

## 验收方法

`webapp_five_cases.py` 覆盖网页原文提交、最终状态、下载接口、视频解码以及负例清除旧视频。`audit_five_case_output.py` 读取实际 HDF5 源状态，验证物体身份、末尾成功保持、松爪、圆柱不被抬升、堆叠高度和干扰物位移。四个有效数据集分别运行 `lerobot_conversion/validate_conversion.py`，验证所有映射数值、视频时间、无损源归档与官方 LeRobot reader。

常规测试为 137 passed、4 skipped；skip 为另行 opt-in 的物理集成和未安装的 PORTAL runtime，本轮真实物理验收通过上述网页案例完成。详细日志、截图、JSON 和测试结果位于 `_validation/five-cases/`。

本轮验证当前本地回退解析配置；不代表任意自然语言或未测试机器人/物体都能成功。UE 保持隐藏窗口运行。没有提交或推送 Git 改动。
